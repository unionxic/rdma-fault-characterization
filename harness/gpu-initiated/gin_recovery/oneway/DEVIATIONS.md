kill 셀 smoke 3회(새 빌드 2회, 기준 빌드 1회) 모두 rank 1의 첫 분류 기록이 rank 1의 끊김 끝 뒤 1 062–1 087 ms에 왔다 `[측정]`.

## 3. 사후 분석 열 (사전 등록 아님)

본 실행 자료를 보기 전(2026-10-08 15:28)에 정의를 고정한다. 계산은 [posthoc_ow.py](posthoc_ow.py)가 하고, 판정에는 쓰지 않는다.
- `n_dead_live_r<r>`: rank `r`의 `liveness=dead` 닫힘 줄 중, 다른 rank의 첫 `GIN/TS: communicator teardown` 줄의 `t0_mono_ms`보다 앞선 것의
  수. 두 시각은 rank 0 kv의 `clock_offset_ms`로 rank 0 시계에 옮겨 비교한다. 다른 rank에 그 줄이 없으면(죽었거나 kill됨) 모든 죽음 줄을 센다.
- 이 열로 같은 판정식을 다시 계산한 값도 함께 보고한다(`n_dead_r<r>` 자리에 `n_dead_live_r<r>`). 판정 표에는 사전 등록 판정만 둔다.
